# Project editing notes

Read HANDOFF.md and README.md before changing this existing site. Page HTML is generated from build-content.mjs and guides.mjs. Browser JS/CSS and the catalog live in dist. Run node build-content.mjs and node --test tests/quiz.test.mjs; preview with node preview.cjs in a retained terminal session.

Design (owner-approved October 28, 2026): editorial layout modeled on The Strategist. Text masthead, mono labels (self-hosted IBM Plex Mono), Newsreader serif, square corners, thin and dotted rules, navy #182a3d with blue #234ee8. Guides are photo-led rows, not cards. Do not add icon tiles, pill chips, drop shadows, rounded cards, or pastel palettes; the owner rejected those as looking AI-made. Guide photos are Unsplash-licensed and credited in build-content.mjs (meta.photo). Preserve plain copy, no emojis, and changeable privacy choices. Owner decision, November 23, 2026 (class conversion checkpoint): the quiz start panel asks the budget question directly instead of showing a Start quiz button and three steps; clicking a budget fires quiz_start and answers question 1. Judge it by quiz_start per session against the Oct 26 to Nov 22 baseline (3 starts from 70 sessions; 3 from 25 Google Ads sessions). Keep quiz answers out of analytics. Ads are restricted to the buying guides in guides.mjs. No public gift-count promotion or full catalog.

Owner decision, October 26, 2026: Google Analytics loads on every production page with Consent Mode v2 (granted by default; denied by default in the EEA, UK, and Switzerland). "Tracking choices" lets visitors opt out. When testing the live site, open it with ?internal=1 first (once per browser) so the visit is tagged traffic_type=internal and excluded by the active GA4 "Internal Traffic" filter; do not filter by IP, because the owner's BYU-Idaho IP is shared with other students. Do not return to opt-in-only analytics or an auto-opening homepage popup: both hid ad visitors from Analytics and Google Ads. The "How it works" dialog opens only from its header button.

Hosting moved to GitHub Pages on October 26, 2026 (repository bcllstr-creator/couplebettergifts). Pushing to main runs .github/workflows/pages.yml, which runs the tests and publishes dist. The custom domain is set in the repository's Pages settings. The old ChatGPT Sites project (.openai/hosting.json) is no longer used. Never claim a change is live until the Pages deployment succeeds. Do not invent affiliate tracking URLs, approvals, live prices, ratings, tests, or rights to merchant photographs. Ordinary retailer links remain labeled as such until actual approved tracking links are supplied.

Copy rule from the owner: do not add “Free to use,” “No account,” reassurance slogans, or redundant labels. Each sentence should help someone choose a gift, use the quiz, or understand a required disclosure.

Owner decision, November 9, 2026: the quiz's length is a selling point. The start panel shows a large "5 / quick questions to a short list" marker, and the hero says "Answer five quick questions." The owner chose "questions" over "steps" knowingly: the gaming path adds a sixth question (which system), and that is acceptable. If the quiz gains a question for everyone, update this claim.
